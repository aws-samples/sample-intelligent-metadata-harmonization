Test Apply All Changes

This is a simple test page to verify the Apply All functionality works correctly.

Expected Behavior:

  • When "Apply All" is clicked, changes should be applied immediately
  • The UI should update to reflect the changes without needing additional actions
  • Only successful changes should be marked as "Applied"
  • Failed changes should continue to show as "Pending" with error messages

Debug Information:

Check the browser console for debug logs:

  • 🔄 MetadataEditor: currentData changed - indicates data state updates
  • 🔄 MetadataEditor: forceUpdateCounter changed - indicates forced re-renders
  • 🔧 MetadataEditor: Applying all schema changes - indicates apply all started
  • 🔧 MetadataEditor: State updates completed - indicates apply all finished

Testing Steps:

  1. Load a CSV file with validation errors
  2. Click "Apply All" on schema changes or validation errors
  3. Verify changes are applied immediately without needing to trigger other actions
  4. Check that only successful changes are marked as applied
  5. Verify failed changes remain pending with appropriate error messages
